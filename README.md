Algorithm Albatross

Algorithm Albatross is a song comparison tool. It is for people who want to find covers and near matches in a music library.

It studies songs to find their instrumental skeletons and matches cover pairs. You can compare two songs, find matches for one song, view section maps and cue points, align songs bar by bar, and sweep tempo. Pairs you confirm or reject are used to calibrate the matching. It runs with a small server that comes with an install script.
